# 食品工厂HACCP控制计划与偏差处置平台

独立React前端工程，采用Fluent UI、Redux Toolkit、RTK Query、React Router、Vite和TypeScript。数据通过浏览器持久化，无需后端。

## 功能

- 生产批次、放行状态、监测点与隔离范围；开工即固化当前已发布控制矩阵。
- HACCP流程图和控制矩阵：**草稿 / 已发布分离**——编辑先保存在草稿区，填写变更原因并发布后才生成只读新版本，新版本只对之后开工的批次生效。
- 控制矩阵按控制点独立编号形成版本链；详情显示版本号与变更前后的限值、频率、纠偏措施，并标明“基于上一版”。
- 已开工批次、隔离批次、相关偏差与审计记录继续指向各自的开工版本，后续发布不会改写旧参数。
- 偏差登记、原因与证据调查、返工/报废分支、复核退回和签字；偏差详情对照开工版本限值并展示与现行版本的差异。
- 未关闭偏差阻止批次放行。
- 完整版本化审计（含控制点版本号）和JSON追溯包导出（含版本链与各批次开工快照）。

端口为`18464`。

```bash
npm install
npm run build
npm run dev
```
